# QR Code Generator

A fast and simple QR code generator built with **Next.js** and **TypeScript**.

## ✨ Features

- Generate QR codes instantly
- Simple and responsive UI
- Download QR codes
- Built with modern Next.js

## 🚀 Try Demo

👉 [Live Demo](https://qr-code-generator101.vercel.app/)

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## 📦 Getting Started

npm install npm run dev

Open [http://localhost:3000](http://localhost:3000) in your browser.
